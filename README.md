# Q8Pixel

Company website for [q8pixel.com](https://q8pixel.com) — websites, mobile apps and hosting in Kuwait.

Plain HTML, CSS and JavaScript; no build step. Open `index.html` in a browser to view it.

- `index.html` — page content (English)
- `script.js` — Arabic translations and the language switch
- `styles.css` — design
- `favicon.svg` — browser-tab icon (small-size cut of the logo)
- `apple-touch-icon.png` — iPhone home-screen icon
- `og-image.png` — link preview image for WhatsApp / social sharing
- `brand/logo/` — official logo files (mark, white mark, small-size cuts, app icon, Instagram picture, full lockup)

Brand colours: Night Navy `#0b1530`, Pixel Blue `#2f6bff`, Gulf Teal `#19d3c5`.
Fonts: Plus Jakarta Sans (Latin), Readex Pro (Arabic).
