# Q8Pixel

Company website for [q8pixel.com](https://q8pixel.com) — websites, mobile apps and hosting in Kuwait.

Plain HTML, CSS and JavaScript; no build step. Open `index.html` in a browser to view it.

- `index.html` — page content (English)
- `script.js` — Arabic translations and the language switch
- `styles.css` — design
- `favicon.svg` — logo mark
